<h2>Capture Rules</h2>
<ul>
  <li>Use realistic but non-sensitive data</li>
  <li>Do not expose email passwords, tokens, or server secrets</li>
  <li>Prefer 1920x1080 for desktop and 375x812 for mobile</li>
  <li>Keep browser zoom at 100%</li>
  <li>If UI changes, update impacted screenshots in same PR</li>
</ul>
